Всё, что нужно для первой партии.

Подключение OBS

  1. Создайте партию

    Создайте турнир и добавьте партию. Заполните имена и роли десяти игроков.

  2. Скопируйте ссылку

    Нажмите «Открыть OBS-оверлей». Ссылка даёт доступ только к публичному состоянию этой партии.

  3. Добавьте источник «Браузер»

    Вставьте ссылку в OBS и укажите ширину и высоту из настроек. Удалите стандартный CSS OBS, если нужен белый фон.

  4. Управляйте эфиром

    Изменения приходят автоматически. Предпросмотр показывает только то, что доступно зрителям.

Данные Polemica

Доступ не подтверждён

Документация API и условия доступа не предоставлены. Импорт турниров, ролей, событий, фотографий, ЛХ, проверок и готовых очков пока недоступен.

Все поля партии можно заполнить вручную. Сервис не рассчитывает очки, результаты и рейтинг.

Как получить доступ

Уточните у команды Polemica официальный адрес API, способ авторизации и разрешённые сценарии использования. Для подключения нужны тестовый турнир, описание полей и ограничения частоты запросов.

Секретные данные

Роли и проверки по умолчанию скрыты. Проверка появляется в OBS только при включённом общем показе. Ссылку OBS можно отозвать и заменить.
