# Polemica Studio

Панель судьи и публичный OBS-оверлей для спортивной мафии. Java 21 / Spring Boot 3.5.16, Angular 21.2.0, PostgreSQL, Flyway, нативный WebSocket и Nginx. Интерфейс на русском языке.

## Быстрый локальный запуск в Windows

Требуются Node.js 24 LTS, JDK 21+ и PowerShell 7. Скрипт также умеет использовать установленный JDK из Microsoft, Eclipse Adoptium или JetBrains. Maven 3.9.11 загружается с Maven Central с проверкой SHA-512, если его ещё нет в `.tools`.

```powershell
.\start.ps1
```

Открыть [демонстрационную панель](http://127.0.0.1:4200/demo). Остановка: `./stop.ps1`. Процессы запускаются без отдельных окон. Журналы — `.runtime/`.

Демонстрационная партия содержит вымышленные имена. Изменения демо сохраняются только в `localStorage` этого браузера. Для постоянной партии откройте «Турниры» и создайте турнир без регистрации. Все сохранённые турниры, партии и изображения доступны в общем рабочем пространстве. Файловая база H2 и изображения находятся в `backend/data/`. Этот режим слушает только loopback и предназначен для локальной работы.

Открытая в другом браузере или в OBS демоссылка **не разделяет** `localStorage` исходного браузера. Для трансляции используйте сохранённую серверную партию.

## Docker / PostgreSQL

```powershell
Copy-Item .env.example .env
# Укажите случайный DATABASE_PASSWORD в .env.
docker compose up --build -d
```

Приложение: [localhost:8088](http://localhost:8088). БД и загрузки хранятся в именованных Docker volumes. При обычной остановке `docker compose down` данные сохраняются. `down -v` удаляет данные.

Для сервера с доступом с телефона используйте домен и HTTPS перед `127.0.0.1:8088`, например конфигурацию [Caddy](deploy/Caddyfile.example). В `.env` задайте `PUBLIC_URL=https://ваш-домен`. API и WebSocket доступны без учётной записи; SMTP и cookie-сессии не используются. Порты БД и backend наружу не публикуются. Стандартный Compose публикует web только на `127.0.0.1`.

Java/PostgreSQL требуют обычного сервера или контейнерного хостинга. Cloudflare Workers в Sites не исполняют этот сервер, поэтому проект не публиковался в Sites.

## Что работает

- Открытый API без регистрации, подтверждения почты, cookie-сессий и CSRF.
- Общее пространство турниров, поиск, столы и партии на десять мест.
- Имена, роли, выступающий, фаза, раунд, статусы «застрелен» / «выбыл» / ПУ.
- Выставление на голосование, ЛХ из трёх цветов или одного руля, хронологическая история проверок Дона и Шерифа.
- Индивидуальные и ролевые фотографии, цвета темы, разрешение и прозрачный фон.
- Панель управления без входа и отдельный маршрут OBS `/overlay/{id}?token=…`.
- WebSocket после фиксации транзакции, повторное подключение и резервная сверка состояния каждые 10 секунд.
- Серверная история, отмена последнего изменения и восстановление версии. Конкурирующие изменения отклоняются с HTTP 409.
- Отзыв OBS-ссылки с закрытием уже подключённых публичных WebSocket.

Победа города/мафии определяется автоматически по живым игрокам; очки и турнирный рейтинг не рассчитываются. В OBS-проекции скрытые роли не передаются; открытый API управления возвращает полное состояние. Роли и проверки раскрываются общими переключателями сразу для всех игроков и записей. Результаты проверок вычисляются по назначенным ролям. Шериф жёлтый, Дон фиолетовый. Перемотчик фаз сохраняет кандидатуры и голоса каждого раунда, а сервер переключает речь по истечении минуты.

## Polemica: исследование и границы реализации

Официальный сайт и контакты команды найдены: [polemicagame.com/about](https://polemicagame.com/about). Документация и подтверждённые условия доступа к турнирному API не получены. Интеграция **не подключена**, и поиск по источнику Polemica честно возвращает HTTP 503. Никакие внешние эндпоинты или поля не придуманы.

Подробности, матрица полей, опубликованные контакты и готовый текст запроса доступа: [docs/POLEMICA-RESEARCH.md](docs/POLEMICA-RESEARCH.md). Адаптер выделен в `PolemicaAdapter.java`, но сетевые вызовы не выполняет. ID Polemica у локального турнира — справочное поле, не признак импорта.

Исходный текст ТЗ обрывается в пункте 7.4; в архитектурном дополнении вместо нескольких таблиц присутствует слово «Таблица». Реализованы доступные требования; отсутствующие фрагменты не трактовались как готовый контракт.

## Проверка

```powershell
# JDK 21+ / Maven 3.9+
cd backend
mvn test
cd ../frontend
npm ci
npm run build
cd ..
node scripts/smoke.mjs
```

`smoke.mjs` требует запущенный локальный dev-сервер, создаёт вымышленные турниры и партии. Проверяет CRUD без сессии и CSRF, фильтрацию OBS, оба WebSocket, конфликт версий, изображения, приватность фото роли и отзыв OBS-ссылки. Внешние адреса скрипт отклоняет.

JUnit проверяет миграции, общий доступ без аккаунта, фильтрацию OBS, историю и валидацию. Тот же набор выполняется на PostgreSQL через Testcontainers, когда запущен Docker. Без Docker тесты PostgreSQL помечаются как skipped, а H2-набор продолжает выполняться.

При разработке проверены сборка Angular, H2-набор и сквозной HTTP/WebSocket-сценарий. Compose проходит проверку конфигурации. При обновлении от 10.11.2026 тесты PostgreSQL выполнены успешно через Testcontainers; сборка полного Compose-окружения отдельно не проверялась. Визуальные проверки выполнялись в браузере на настольном и узком экране.
