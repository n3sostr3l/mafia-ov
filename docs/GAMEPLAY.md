# Игровое управление

Обновление от 10 ноября 2026 года.

## Роли и проверки

Роли раскрываются одним переключателем **«Показывать все роли в OBS»**. Выключение скрывает все десять ролей и ролевые фотографии. Отдельного раскрытия игрока больше нет. Шериф жёлтый (`theme.sheriff`), Дон фиолетовый (`theme.don`); цвета настраиваются отдельно. Старый `theme.special` автоматически становится цветом Шерифа.

В проверке выбираются назначенный проверяющий игрок и цель. Роль проверяющего берётся из состава, результат задаёт сервер: Шериф видит мафию/Дона чёрными, остальных красными; Дон видит Шерифа либо «не шериф». Исправление ролей обновляет результаты проверок. Если меняется роль самого проверяющего на обычную, сначала удалите его проверки.

**«Показывать все проверки в OBS»** включает сразу всю историю, выключение скрывает её. Индивидуальных разрешений нет. Боксы подписаны: «Мирный» — красный, «Мафия» — чёрный, «Шериф» — жёлтый, «Не шериф» — нейтральный серый (отрицательная проверка Дона не определяет команду). Номер проверяющего публично не передаётся при публикации проверок.

## Фазы, кандидатуры и голоса

Перемотчик: **Подготовка → День → Голосование → Ночь → День следующего раунда**. Раунд увеличивается только при переходе из ночи в следующий день; обратное движение возвращает предыдущий раунд. Переход назад останавливает часы для просмотра истории.

Каждый раунд хранит собственные кандидатуры, голоса, состав голосующих, выбывшего по голосованию и прошедшие речи. Переходы вперёд и назад не очищают эти данные. Выбывших нельзя вновь выставить: их кнопки кандидатур отключены и запрос дополнительно проверяется сервером.

В фазе голосования выберите кандидатуру и отметьте проголосовавших. У каждого игрока один голос; выбор другой кандидатуры переносит голос. Кнопка «Завершить голосование» отмечает выбранного кандидата выбывшим. Число голосов и номера проголосовавших остаются в истории. Состав участников фиксируется при начале голосования, поэтому исторический голос можно исправить после выбывания участника; это не позволяет заново выставлять выбывших кандидатов.

**Первый ушедший (ПУ)** — один номер на всю партию. Первый переход из живого состояния определяется автоматически; судья может исправить его, выбрав другого выбывшего. Новое назначение заменяет прежнее; флаг `pu` автоматически совпадает с этим единственным номером. Возвращение назначенного игрока в игру снимает отметку.

## Минута речи

В активной дневной фазе речь длится 60 секунд. Оставшиеся секунды и уменьшающаяся линия видны в панели и OBS. Есть пауза, продолжение и ручная передача следующему. По окончании минуты сервер передаёт слово следующему живому месту, пропуская выбывших и уже выступивших в этом раунде. После полного круга начинается голосование. Первое место нового дня сдвигается по кругу с номером раунда; судья может начать речь с выбранного места.

В сохранённой партии дедлайн хранится в БД и обрабатывается сервером независимо от браузера судьи. В демо часы обслуживаются открытой панелью; закрытое демо не имитирует сервер. Восстановление версии из истории оставляет минуту на паузе.

## Завершение

Для начала требуются 6 мирных, 2 мафии, один Дон и один Шериф. После изменения статусов корректного состава:

- живых мафии и Дона нет — победа города;
- живых мафии и Дона не меньше остальных живых игроков — победа мафии.

Партия переходит в завершённую фазу, минута останавливается, в панели и OBS появляется соответствующий бокс. Исправление ошибочного статуса автоматически пересматривает результат и при необходимости возвращает активную фазу. Турнирные очки и рейтинг не рассчитываются.

Проверки: `mvn -f backend/pom.xml verify`, `npm --prefix frontend run test:gameplay`, `npm --prefix frontend run build`. Серверный набор включает PostgreSQL/Testcontainers и проверку переключения речи планировщиком без браузера.
