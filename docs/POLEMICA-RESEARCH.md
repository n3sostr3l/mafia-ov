# Исследование Polemica

Дата проверки: 30 октября 2026 года. Статус интеграции: **UNVERIFIED / не подключена**.

## Подтверждённые первичные источники

1. [О проекте](https://polemicagame.com/about): сайт официально описывает отдельное приложение для турниров и игр в реальной жизни и ссылается на `/app`. Турнирный продукт следует отличать от онлайн-игры на основном сайте.
2. На той же странице опубликованы контакты: CTO — [Юрий Строт](https://t.me/fantom_polemica), поддержка — [Polemica Help](https://t.me/polemica_help). Поддержка присутствует в навигации официального сайта. Это практические каналы для запроса доступа, а не подтверждение доступности API.
3. [Контактная информация](https://polemicagame.com/info/contact-info) содержит реквизиты оператора. Публичного контракта API на прочитанных страницах нет.
4. [Мирный зритель](https://polemicagame.com/audience) указан официальным сайтом как отдельный продукт. Это само по себе не означает наличие API турнирных партий.

На момент проверки страницы «О проекте» и «Контакты» вернули HTTP 200 и были прочитаны. Переход `/app` и загрузка JS-бандла периодически завершались тайм-аутами. Поисковый инструмент несколько раз возвращал 503; официальный домен удалось установить через браузерный поиск и затем проверить прямыми запросами. Предварительные проверки похожих доменов не подтверждают их принадлежность Polemica и не использовались как источники интеграции.

Не проверены авторизация в турнирном продукте, внутренние запросы авторизованного клиента и доступ к реальным данным: нет тестового аккаунта, турнира, документированного контракта или предоставленного ключа. Статус «не подтверждено» не означает «API отсутствует».

## Как запросить доступ

Готовый текст для ручной отправки CTO или поддержке (сообщение агентом **не отправлялось**):

> Разрабатываем OBS-оверлей для спортивной мафии с панелью судьи. Хотим получать готовые данные турнира, столов и партий без пересчёта результатов и рейтинга. Подскажите, доступен ли официальный API турнирного приложения и разрешена ли такая интеграция? Нужны документация или OpenAPI, базовый URL, способ авторизации, минимальные read-only права и тестовый турнир. Какие данные доступны: состав, места, имена, фото, роли, статусы, выступающий, голосование, ЛХ, проверки Дона/Шерифа, итоги и очки? Есть ли события/WebSocket, ограничения частоты, условия хранения фото и правила публичного показа скрытых ролей? Просим также указать контакт для согласования доступа и версионирования API.

## После получения доступа

1. Зафиксировать разрешённый контракт и образцы обезличенных ответов. Не переносить внутренние URL онлайн-игры в адаптер турниров без подтверждения применимости.
2. Хранить ключ только на сервере. Не передавать его в OBS URL, JS, журнал или публичные ответы.
3. Реализовать подтверждённые операции поиска и чтения с тайм-аутами, ограничением запросов и обработкой 401/403/429/5xx. Период опроса выбирать по разрешённым лимитам; не считать произвольные 10 секунд разрешением внешней платформы.
4. Хранить внешний снимок отдельно от ручных переопределений, с источником и временем получения каждого поля. Ручное изменение сохранять при очередном импорте до явного сброса судьёй.
5. Добавить контрактные тесты по реальным ответам и отдельные тесты приватности всех внешних полей. Для событий предусмотреть восстановление последовательности после разрыва соединения.
6. Показывать только готовые результаты и очки; не добавлять собственный расчёт.
