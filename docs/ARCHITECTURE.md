# Архитектура

Один Spring Boot backend, один Angular frontend, PostgreSQL и Nginx. Сервис не выполняет турнирный скоринг. H2 в профиле `dev` предназначен для автономной локальной проверки.

## Модули

- `OpenApiConfig`: открытый stateless API, CORS без credentials и HTTP-заголовки. Контроллеры аккаунтов и почтовая регистрация удалены.
- `GameController`: DTO и HTTP. `GameService`: общие ресурсы, транзакции, ревизии, снимки истории и публичная проекция. `GameValidator`: правила игрового состояния и разрешённые изображения.
- `LiveUpdates`: нативный WebSocket, открытое подключение панели или проверка OBS-токена, отправка после commit, повторная проверка доступа при каждой отправке.
- `ImageController`: загрузка, проверка реального формата и размеров, повторное кодирование PNG, общая и OBS-выдача.
- `PolemicaAdapter`: граница будущей подтверждённой интеграции. Текущая реализация сообщает неподтверждённый статус и не выполняет внешние запросы.

## Хранение и конкурентные изменения

Таблицы: `studio_users`, `tournaments`, `games`, `game_events`, `uploads`. `studio_users` — неиспользуемая таблица старой версии, она не отображается в ORM и не имеет API. Миграция V3 удаляет связи владельцев; существующие турниры, партии и загрузки становятся общими без потери данных. Миграции Flyway — единственный источник схемы; Hibernate проверяет схему, но не генерирует её. Игровое состояние хранится версионируемым JSON-снимком. История содержит полный снимок каждой сохранённой версии; интерфейс запрашивает последние 50, старые записи автоматически не удаляются.

Изменение содержит ожидаемую ревизию. Сервис блокирует строку партии, сравнивает ревизию, валидирует новый снимок, фиксирует его и событие в одной транзакции. При конфликте — HTTP 409 без перезаписи чужого изменения. Восстановление истории проходит через ту же проверку и создаёт новую версию.

## Публичные данные

Публичный токен — отдельные случайные 256 бит, не cookie, пароль и не ключ Polemica. Маршруты управления открыты и возвращают полное состояние без сессии. OBS HTTP и WebSocket принимают токен конкретной партии и получают одну и ту же серверную проекцию. Фильтрация OBS управляет содержимым трансляции; API управления остаётся общедоступным.

- Роль заменяется на `UNKNOWN`, пока не включён общий показ всех ролей.
- Проверки полностью удаляются из ответа до включения общего переключателя показа проверок.
- Настройки ролевых изображений удаляются из публичного ответа.
- Фото роли не выбирается для скрытой роли, иначе картинка косвенно раскрыла бы секрет.
- Email, хеши паролей, владелец, токены и служебные записи в публичную модель не входят.
- Публичная выдача изображения повторно проверяет токен и присутствие изображения в текущей публичной проекции.
- Отзыв ссылки меняет токен в БД, закрывает старые публичные сокеты и делает старые ссылки на состояние и фото недействительными.
- Nginx пишет `$uri` без query string, поэтому OBS-токены не попадают в штатный access log. Referrer-Policy — `no-referrer`.

WebSocket панели передаёт полное состояние без сессии. OBS-сокет проверяет свой токен при каждой отправке.

## Изображения

Приоритет, реализованный в `GameService.effectivePhoto` и frontend `photoId`:

1. Индивидуальная загрузка судьи.
2. Фото роли при включённой настройке. Для публичного показа — только когда включён общий показ ролей.
3. Фото, полученное из Polemica. Сейчас адаптер не подключён, поэтому этот источник не заполняется.
4. Встроенный графический аватар по умолчанию.

Редактор показывает действующий источник. Загрузки допускают только JPEG/PNG до 5 МБ; проверяются сигнатура, реальный формат, ширина и высота до 4096, максимум 16 мегапикселей. Изображение уменьшается до 1024 по длинной стороне и перекодируется в PNG без исходных метаданных. SVG/HTML и произвольные внешние URL не принимаются. Файлы получают серверный UUID и хранятся вне web-root. Все загрузки доступны в общем рабочем пространстве.

При сбое записи БД может остаться неиспользованный файл; автоматическая очистка и интерфейс удаления неиспользованных загрузок пока отсутствуют. Удаление фото в интерфейсе снимает назначение, но не удаляет исходный файл из хранилища.

## Отображение событий

Серый фильтр применяется к `.player-visual`. ЛХ, цвета, руль и ПУ — соседние элементы `.player-extras`, фильтр на них не распространяется. Анимация выстрела масштабируется относительно неизменного центра и ограничена размерами карточки; выбывание голосованием использует другой эффект. `prefers-reduced-motion` выключает анимации.

Сетка OBS всегда содержит 10 мест. Ширина и высота Browser Source задаются настройкой партии и должны совпадать с размерами источника в OBS. Панель показывает компактную публичную проекцию; точную композицию в выбранном разрешении можно открыть отдельной вкладкой.

## Ограничения развёртывания

Один экземпляр backend: подписчики WebSocket находятся в памяти. Для горизонтального масштабирования понадобится общий канал событий. Авторизация и SMTP не используются. Для резервного копирования сохраняйте БД и загрузки совместно.

## Игровые действия и таймер (10.11.2026)

`GameRules` обрабатывает фазы, автоматическую победу, результаты проверок и минуты речи. Раунды хранят собственные кандидатуры, голоса, состав участников голосования и очередь прошедших речей. `firstDeparted` — один номер, а не независимые флаги игроков.

Дедлайн речи сохраняется в JSON и индексированной колонке `games.speech_deadline` (Flyway V2). `SpeechScheduler` каждые 250 мс выбирает истёкшие дедлайны; сервис блокирует строку и повторно сверяет дедлайн. Обновление получает новую ревизию и рассылается по WebSocket после commit. Дублирующие тики не переключают речь повторно. Закрытие браузера не останавливает серверную минуту; просроченные интервалы после перезапуска сервера последовательно восстанавливаются. История восстанавливается с приостановленным таймером.

`Check.checker` используется только приватно для вывода роли проверяющего. Публичная проекция удаляет этот номер, чтобы публикация проверки не раскрывала место Дона или Шерифа при скрытых ролях. `revealRole` и `published` сохранены для чтения старых JSON, но больше не управляют публичным показом.
